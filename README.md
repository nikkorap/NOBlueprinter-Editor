# Blueprinter Editor
An unofficial Unity project for creating mods for Nuclear Option.

Blueprinter lets modders use the game models, prefabs, textures, ScriptableObjects and other assets in their mods like normal Unity assets, without including those assets in the built *.nobp AssetBundles.

Nuclear Option does not provide official mod support. Mods may break with game updates.

The mods created by this project are loaded ingame by the [BepInEx Blueprinter Plugin](https://github.com/nikkorap/NOBlueprinter-Releases).

## Getting Started
Requirements and setup instructions are in the Blueprinter [Editor Guide](GUIDE.md).
Setup takes 1-3 hours. The project ZIP is on the [Releases page](https://github.com/nikkorap/NOBlueprinter-Editor/releases/latest).


For a more visual guide you can refer to [Draken’s Blueprinter Guide](https://docs.google.com/presentation/d/1DRlvonA4_T1rgQ8DB_7Mmis6tjg7ARDbe6uS63d4hSA/edit?usp=sharing)
